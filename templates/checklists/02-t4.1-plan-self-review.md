# T4.1 · Plan 自评 5 条 Checklist

> AI 起草方案后必须自评本 5 条，输出结构化记录附 PR / Issue。任何 ❌ 必须**改方案**或**回流 T2**，不允许跳过。

| # | 条目 | 判据 | ✅/❌ | 异常备注 / 修复 |
|---|---|---|---|---|
| 1 | 消费 spec / plan / contracts 完整 | 方案显式引用 `spec.md` + `plan.md` + 具体 contract 锚点 |  |  |
| 2 | 不修 feature 级 spec | 方案只在 issue body / `tasks.md` 行展开（修了 → 回流 T2）|  |  |
| 3 | DoD ≤ 3 条 + 可机检 | DoD 含 quickstart 场景或 CI 命令 |  |  |
| 4 | 风险 ≥ 1 + 降级 | 至少 1 风险条目带 fallback |  |  |
| 5 | 留痕：候选 / 选定 / 排除 | 涉及候选选择时三段齐全（候选 / 选定 / 排除理由都写）|  |  |

## 起草信息

- Feature ID：<id>
- Task ID：<T-n>
- 关联 Issue：#<N>
- 起草工具：<Claude / Cursor / Copilot / Codex> + `gate-checklist` skill plan 模式
- 起草时间：<YYYY-MM-DD HH:MM>

## 审批

- 自评：本 AI（5 条结论）
- Human Approver：<PM-Tech 或 Tech Lead>
- 通过条件：全 ✅
